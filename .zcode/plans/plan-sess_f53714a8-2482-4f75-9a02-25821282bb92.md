# GUI 主题/布局可选化:设置里集成三套设计

目标:把设计稿 A(石墨工作站)、B(极光玻璃)做成**界面风格**选项,C(指令甲板)做成**布局模式**选项,用户在设置里自由组合(如"石墨 + 甲板")。分两个独立 commit。

## Commit 1 · 新增两个界面风格(石墨 graphite / 极光 aurora)

### 1. 主题类型与注册(`frontend/src/lib/terminalSettings.ts`)
- `ThemeMode` 增加 `"graphite" | "aurora"`,`THEMES` 数组同步(现有 dark/nordic/light 不动)

### 2. CSS 变量组(`frontend/src/styles.css`)
- `[data-theme="graphite"]`:中性石墨色阶(bg #0b0d10 / panel #12151a / line #1f242c),accent 换青绿 #57d6c9 系;附加规则收紧圆角(`.rounded-xl/2xl/3xl → 6px`)、状态栏/标签区去掉 pill 底色改 1px 发丝线
- `[data-theme="aurora"]`:深蓝绿基调变量 + panel/sidebar 背景改半透明 rgba;通过转义选择器给 `.bg-[var(--panel-bg)]/.bg-[var(--sidebar-bg)]` 容器统一加 `backdrop-filter: blur(18px)`;无壁纸时 app-root 用内置极光渐变兜底
- 两套都完整复用现有变量名,组件层零改动(石墨的圆角/发丝线用属性选择器覆盖)

### 3. 极光壁纸全窗口化(`frontend/src/App.tsx` app-root 处小改)
- theme 为 aurora 且设置了壁纸时,把壁纸以 `background-size: cover` 铺在 app-root 层(现在只在终端区),玻璃面板透出壁纸形成景深

### 4. 设置面板(`frontend/src/components/settings/SettingsPanel.tsx`)
- 主题选择 grid 自动扩为 5 项(THEMES.map 已驱动),补两个 swatch 配色与名称"石墨工作站/极光玻璃"
- 持久化走现有 theme storage key,无新增机制

## Commit 2 · 布局模式:经典(classic)/ 甲板(deck)

### 1. 状态与设置项
- `layoutMode: "classic" | "deck"`,localStorage `ldyssh.layout.mode`,SettingsPanel 外观区加一组单选("经典标签页 / 甲板会话栈")

### 2. 新组件 SessionStack(App.tsx 内,置于 TerminalWorkspace 旁)
- 垂直会话卡片列表:状态点 + 标题(双击重命名,与现标签一致)+ cwd(terminalCwds 现成)+ 跳板徽章(connectParams.jumpChain 长度 → "跳板×N")+ 中键/按钮关闭
- 头部"+ 新建"入口,底部显示传输任务数(有任务时)
- 复用现有 onActivate/onClose/onRenameTab/openTabMenu 逻辑

### 3. TerminalWorkspace 布局分支
- deck 模式:隐藏横向会话标签条(工具栏其余按钮保留),工作区变为 `SessionStack(240px) + 终端区` 两列
- 右侧工作栏 deck 模式默认收起,留一个悬浮小把手展开(复用现有 sidePanel 开关)
- classic 模式:完全现状,零影响

## 验证
- `npm run typecheck && npm test && npm run build`(build 自动同步 ui 到 C++ 目录;纯前端改动无需重编 exe)
- 手动冒烟(你):设置里切换 5 主题 × 2 布局组合,重点看 aurora 无壁纸兜底、deck 多会话滚动、标签重命名/中键关闭在两种布局下一致
- 现有测试如对主题按钮数量有断言则同步适配

## 风险与边界
- aurora 的 backdrop-filter 在远程桌面/虚拟机上可能无模糊效果,仅视觉降级无害
- deck v1 不含会话卡片的 CPU 实时迷你条(需要为所有会话轮询监控,成本高),留作后续增强,先显示 cwd + 状态 + 跳板信息
- 两个 commit 独立,可分别 revert
